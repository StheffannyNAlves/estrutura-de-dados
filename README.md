# Estrutura de Dados

Implementações de algoritmos e estruturas de dados desenvolvidas durante o curso EXA806 — Estruturas de Dados (Engenharia de Computação, UEFS).

Linguagens: C e C++.

## Estrutura

```
estrutura-de-dados/
├── grafos/
│   ├── bfs/
│   ├── dfs/
│   ├── scc/
│   ├── topologica/
│   ├── dijkstra/
│   ├── dsu/
│   └── kruskal/
├── arvores/
│   ├── avl/
│   └── btree/
├── tabelas-hash/
├── ordenacao/
│   ├── quicksort/
│   ├── mergesort/
│   └── heapsort/
└── estruturas-basicas/
    ├── listas/
    ├── pilhas/
    └── filas/
```

Cada pasta contém a implementação e um README com análise do algoritmo — quando usar, complexidade e limitações.

## Como compilar

```bash
# C
gcc -o programa arquivo.c

# C++
g++ -std=c++20 -o programa arquivo.cpp
```
